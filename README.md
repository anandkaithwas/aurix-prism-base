# AURIX

An independent Android music-player project derived from Prism.

**Product rule:** preserve the complete Prism feature set as the baseline. AURIX AI DJ Studio and Visualizer Studio enhancements are additive and optional. Standard playback must continue to work with DJ mode disabled.

## Source and planning
- Android source fork: https://github.com/anandkaithwas/aurix-prism-base
- Product architecture and planning: https://github.com/anandkaithwas/aurix-music

## Development status
- Forked from Prism upstream commit `be2035a76c4690724e35bc1a98e6bc62ab8e82c1`.
- Independent Android application ID: `com.aurix.music`.
- First branding/build-pipeline changes are being prepared. CI and APK output must be verified before calling the build successful.
